# Java 商品管理コンソールアプリ

## 概要
Javaの基礎文法とオブジェクト指向プログラミングの習得を目的に作成した商品管理アプリです。

## 開発環境
- 言語：Java
- 開発環境：Visual Studio Code
- 開発時期：2026年10月〜11月
- v1.0完成目標：2026年11月29日

## 実装機能
- 商品一覧表示
- 商品名による検索
- 商品販売・在庫減算
- 在庫補充
- 在庫不足・不正数量のチェック
- 食品の賞味期限表示
- 商品登録（追加：2026年11月15日までに実装・動作確認）
- 価格・在庫数の整数入力チェック（追加：2026年11月14日）
- メニュー番号の整数入力チェック（追加：2026年11月14日）
- 販売数量・補充数量の入力チェック（追加：2026年11月14日）
- 商品名の重複登録防止（追加：2026年11月15日）

## 更新履歴

### 2026年11月14日：入力値の検証機能
- 商品登録時、価格・在庫数に整数以外が入力された場合は登録を中断する処理を追加
- 価格・在庫数の負数を拒否し、在庫数0は許可することを確認
- メニュー番号が整数でない場合の入力エラー処理を追加
- 販売数量・補充数量について、整数以外・負数・0などの不正入力を拒否する動作を確認
- 不正入力後にメニューへ復帰できることをテスト

### 2026年11月15日：商品名の重複登録防止
- `ArrayList<Product>` を拡張for文で走査し、`getName()` と `equals()` で商品名を比較
- 同名の商品が存在する場合は `isDuplicate` フラグを立て、価格・在庫入力前に登録処理を中断
- 既存商品「みかん」の再登録拒否を確認（TC21）
- 新規商品「バナナ」（120円・在庫7個）の登録成功を確認（TC22）
- 追加済みの「バナナ」の再登録拒否と、商品一覧が4件のまま維持されることを確認（TC23）

## 実行方法

```bash
javac -encoding UTF-8 Main.java
java Main
```

※日本語入力が正しく読み取れない場合は、ターミナルとScannerの文字コード設定を確認してください。Windows環境で標準入力がMS932の場合は、`new Scanner(System.in, "MS932")` を使用することで改善した実績があります。
