
# Java 商品管理コンソールアプリ

## 概要
Javaの基礎文法とオブジェクト指向プログラミングの習得を目的に作成した商品管理アプリです。

## 開発環境
- 言語：Java
- 開発環境：Visual Studio Code
- 開発時期：2026年10月〜11月

## 実装機能
- 商品一覧表示
- 商品名による検索
- 商品販売・在庫減算
- 在庫補充
- 在庫不足・不正数量のチェック
- 食品の賞味期限表示

## 学習内容
- クラス・インスタンス・コンストラクタ
- カプセル化・継承・オーバーライド
- ポリモーフィズム
- ArrayListによるデータ管理
- Scannerによる入力処理
- 条件分岐・繰り返し処理
- デバッグ・正常系／異常系テスト

## 実行方法

```bash
javac -encoding UTF-8 Main.java
java Main
```

※日本語入力が正しく読み取れない場合は、ターミナルとScannerの文字コード設定を確認してください。
